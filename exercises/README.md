# Temporal 迁移练习

先完成[五阶段学习路径](../docs/learning-path.md)与[自测](../docs/self-check.md)，再把学到的机制迁移到新的业务。每次练习都先写设计、预测和验收证据，再查看参考实现。

## 01 · 资料审核

进入[资料审核题目](01-transfer/01.01-document-review/problem/readme.md)，在独立 Workflow 中实现准备资料、人工审核、归档与失败清理。题目提供可运行的 CLI、模拟业务活动和独立 SQLite 存储，编排部分留给学习者完成。

验收覆盖正常完成、等待时恢复、结果未知后的业务幂等，以及超时 / 取消后的清理。用[实验记录模板](../docs/experiment-record-template.md)留下同一次 Run 的事件、来源与实际业务效果。参考实现的入口放在题目之后，自动测试参考实现也不代表自己的作业已经完成。

练习使用专用 Task Queue，不会出现在订单列表；当前订单服务可以继续运行。练习进程操作只针对自己的练习 Worker。切换题目与参考实现前，先结束练习 Run、停止对应练习 Worker，避免不同编排同时处理同一队列。
